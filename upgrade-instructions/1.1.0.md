# 1.1.0

## New Environment Variables

### Runtime Configuration Variables (in `.env.js`)
The following configuration variables were introduced to support `Attached TDrive files in events` in 1.1.0:
- `TDRIVE_ENABLED` (boolean): Set to `true` to enable attaching TDrive files to events. Defaults to `false`.
- `TDRIVE_INTENT_URL` (string): The URI template (RFC 6570 style) for TDrive integration. Example: `"https://{localpart}.example.com"`
