# 1.1.0

## New Environment Variables

### Runtime Configuration Variables (in `.env.js`)
The following configuration variables were introduced to support `Attached TDrive files in events` in 1.1.0:
- `TDRIVE_ENABLED` (boolean): Set to `true` to enable attaching TDrive files to events. Defaults to `false`.
- `TDRIVE_INTENT_URL` (string): The URI template (RFC 6570 style) for TDrive integration. Example: `"https://{localpart}.example.com"`

The following configuration variable was introduced to support `Meet integration` in 1.1.0:
- `MEET_BACKEND_INTEGRATION` (boolean): Set to `true` to have the side service create the Meet room (`POST /api/videoconference`) instead of appending a random code to `VIDEO_CONFERENCE_BASE_URL`. Requires `meet.enabled=true` on the side service. `VIDEO_CONFERENCE_BASE_URL` stays required: it enables the video conference field and serves as the fallback when the side service answers `404`. Defaults to `false`.
